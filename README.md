# saens

入力音声そのものの断片を切り貼りして、同梱の元曲（`元データ.mid` ＋ その原曲 `2.wav`）を
「無理やり歌わせる」——いわゆる空耳／人力系ミームの合成を自動化した実験的な TypeScript ライブラリです。

元曲（参照 `2.wav`）の各瞬間について、その発音（音素）に似ていて MIDI ノート近傍のピッチを持つ
入力断片を選び、**ピッチ無加工のまま verbatim で**貼り付けます。断片は長めの塊のまま連続再生し
（既定で約 7 割が連続）、語の切れ目でだけ別位置へ飛ぶので、入力自身の言葉が元曲に強引に乗った
「連呼と歌の中間」の質感になります。狙い所は自然な発音そのものではなく、この“無理やり感”です。

## 最小コマンド（npx）

```bash
npx @kongyo2/saens --audio input.wav --out output.wav
```

`元データ.mid` と、その原曲 `2.wav` はパッケージに同梱されます。`--audio` が切り貼りされる素材（声）で、
`2.wav` は歌詞・発音のガイド（合わせ先）として常に内部で使われます。

## 質感の調整

`spliceAudioFromMidi` のオプションで“無理やり感 ⇔ クリーンさ”を振れます。

- `continuityMargin` … 大きいほど入力の塊が長く連続（原音寄り／連呼寄り）。小さいほど細かく貼り替え。
- `onsetSensitivity` … 子音の立ち上がりで別断片に飛ぶ強さ。上げると発音は明瞭になるが“無理やり感”は薄れる。
- `pitchTolerance` … MIDI 音程からどれだけ外れた入力まで許すか（オクターブ畳み込み）。
