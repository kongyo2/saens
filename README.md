# saens

入力音声そのものの断片を切り貼りして、同梱の元曲（`元データ.mid` ＋ その原曲 `2.wav`）を
「無理やり歌わせる」——いわゆる空耳／人力系ミームの合成を自動化した実験的な TypeScript ライブラリです。

元曲（参照 `2.wav`）の各瞬間について、その発音（音素）に似ていて MIDI ノート近傍のピッチを持つ
入力位置を選び、そこから**入力の生サンプルをそのまま（verbatim に）**一定長スライスして貼り付けます。
出力は合成音ではなく**入力そのものの生スライスの寄せ集め**（既定で 1 スライス ≈ 0.15 秒、繋ぎ目だけ
短くクロスフェード）。手作業の切り貼りと同じく、入力全体を前後に飛び回って（実測: 平均ジャンプ幅
数十秒・約半分は後方ジャンプ）元曲へ並べ替えます。狙いは自然な発音ではなく、元ネタを生のまま
元曲に強引に乗せる“無理やり感”です。

## 最小コマンド（npx）

```bash
npx @kongyo2/saens --audio input.wav --out output.wav
```

`元データ.mid` と、その原曲 `2.wav` はパッケージに同梱されます。`--audio` が切り貼りされる素材（声）で、
`2.wav` は歌詞・発音のガイド（合わせ先）として常に内部で使われます。

## 質感の調整

`spliceAudioFromMidi` のオプションで“無理やり感 ⇔ クリーンさ”を振れます。

- `minSliceSeconds` … 1 スライスの最短長。長いほど生の塊が大きく「元ネタそのまま感」が強い（既定 0.15）。
- `continuityMargin` … 最短長を超えた後、どれだけ得なら切り替えるか。大きいほど塊が長く連続する。
- `crossfadeSeconds` … 繋ぎ目のクロスフェード長。短いほどスライスが生（verbatim）のまま（既定 6ms）。
- `onsetSensitivity` … 子音の立ち上がりで切り替える強さ。上げると発音は明瞭だが生スライスが分断される（既定 0＝無効）。
- `pitchTolerance` … MIDI 音程からどれだけ外れた入力まで許すか（オクターブ畳み込み）。
